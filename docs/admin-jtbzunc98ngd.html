Connect to GitHub

This page edits the live website by saving changes to its GitHub repository. Enter a GitHub access token that has write access to DarskeeWorks-Services/dgtechandload.com. The token stays in this browser only and is never put into the website.

How do I get a token?
  1. Open GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Resource owner: DarskeeWorks-Services. Expiration: 90 days (or your choice).
  3. Repository access: Only select repositories → dgtechandload.com.
  4. Permissions → Repository permissions → Contents: Read and write. Nothing else is needed.
  5. Generate, copy the token, and paste it above. Treat it like a password.

Only tick "Remember" on your own phone/computer. Anyone with the token can change the website — if it leaks, delete it on GitHub and make a new one.

Changes go live on the website about a minute after saving. Only add real offers, partners and ads — sponsored ads are labelled "Sponsored" and affiliate links show a commission notice automatically.
