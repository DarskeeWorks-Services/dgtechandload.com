Connect to GitHub

This page edits the live website by saving changes to its GitHub repository. Enter a GitHub access token that has write access to DarskeeWorks-Services/dgtechandload.com. The token stays in this browser only and is never put into the website.

First time? Get your token (one-time setup, about 2 minutes)

You only do this once. Afterwards, turn on Password login and you'll just type your password.

Option A — simplest (works right away)

  1. Open GitHub: new classic token — the name and the public_repo box are already filled in.
  2. Choose an expiration (e.g. 1 year), scroll down, tap Generate token, copy it and paste it above.

This token can edit all public repositories you have access to — keep it private.

Option B — safest (only this website)

  1. Open GitHub: new fine-grained token
  2. Check: Resource owner DarskeeWorks-Services · Repository access Only select repositories → dgtechandload.com · Repository permissions Contents: Read and write.
  3. Generate, copy and paste it above.
  4. Then approve it: open DarskeeWorks-Services settings → left menu Personal access tokens → Pending requests → approve. Until approved it can only read, and saving shows an error.

Only tick "Remember" on your own phone/computer. If a token leaks, delete it on GitHub and make a new one.

Changes go live on the website about a minute after saving. Only add real offers, partners and ads — sponsored ads are labelled "Sponsored" and affiliate links show a commission notice automatically.
